# Cloud Resume Journey

A long-term cloud infrastructure portfolio documenting my education, projects, and technical growth.

## Project Goals
- Build and maintain a website to serve as my interactive résumé and technical portfolio
- Document my learning journey
- Apply academic concepts to a real-world use case

## Use of AI and LLMs
This project was built in collaboration with ChatGPT.
### How AI Was Used

- Reviewing and refining code and documentation
